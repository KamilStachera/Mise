# Twilight quiz: third batch

Added 60 original Polish questions in `frontend/src/zmierzch/questions/paczka-3.json`, bringing the bank from 200 to 260 entries: 18 medium and 42 hard. Source tags: 13 film, 31 book and 16 shared/comparative. Existing question IDs and entries are preserved. The existing eager JSON import includes the new file automatically.

## Editorial scope

- Only difficulty 2 and 3: supporting characters, motives, props, adaptation differences, vampire abilities, music and production details.
- Each entry has one correct option, three distinct distractors and an explanation.
- Book-only details are marked `ksiazka`; adaptation comparisons explicitly identify both versions. Two questions explicitly cover the Bree Tanner companion novella, and the Esme biography question identifies supplementary author material in its note.
- Polish prompts and answers are newly written paraphrases, not claims to reproduce a particular published translation. Original names, song titles and the Italian in-universe term are retained where needed.
- Translation traps are explained: `mountain lion` means puma; `niece` does not specify a brother's or sister's daughter. The description of Demetri's mental tracking is labelled a paraphrase.
- The baseball question concerns the start of the game because the book changes positions when the visitors approach. The venom question compares Nahuel and Renesmee without turning their cases into an unrestricted biological rule.
- Human casting preferences are distinguished from actual casting offers. Fictional Quileute lore is identified as part of the novel.

## Verification

Run from `frontend`:

```text
npm run test:zmierzch
npm run build
```

The data validator checks all 260 entries for schema values, unique IDs, normalized duplicate question text, four distinct options and the existing editorial regression assertions. Natural Polish, factual scope and semantic overlap also require editorial review; the validator does not establish factual accuracy by itself.

Results: both commands passed. The Vite build retains its bundle-size warning (main JavaScript chunk above 500 kB). `git diff --check` passed; both new files were also checked for trailing whitespace. All 60 new IDs have evidence entries. The closest question-text matches against the previous 200 entries were reviewed and concern different facts.

This is a local static-content addition. It does not change database records, APIs, migrations, MCP tools or generated culinary context. Publishing it requires the normal frontend deployment, which was not performed.
