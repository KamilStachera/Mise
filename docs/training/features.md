# Training module ("Trening") — feature set

Status: **agreed** (2026-11-08). P1 done, P2 tooling done.

She was about to buy Anna Lewandowska's *Diet & Training by Ann* (dieta.hpba.pl, ~90 zł/month).
The diet side is already covered by Pichci's diary (and she is moving to catering), so we build
the **training** side: a plan, what every exercise works, a video of how to do it, and what to
focus on / not do during a rep. Anna's own videos are replaced by YouTube.

Decisions:

- **Video: both kinds.** A plan day is either a list of exercises (each with a demo clip, muscle
  map and tips, logged as sets × reps × kg) or one full-length follow-along YouTube workout.
- **Equipment:** home with some kit (dumbbells, bands, kettlebell) **and** gym.
- **Catalog:** ~870 exercises seeded from [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (The Unlicense — public domain; vendored in `backend/Data/Seed/free-exercise-db/`, pinned to
  `ExerciseImport.UpstreamSha`). An agent adds the Polish name, steps, tips, mistakes and a YouTube id.
- **Plan:** generated by an agent from a short training questionnaire; editable in the UI; adjusted
  later from logged sessions.
- Out of scope: hosting video, audio coach, meditations, dietitian chat, payments.

## DTBA vs what we build

| DTBA | Pichci |
|---|---|
| Instructor videos per workout | YouTube demo per exercise (verified ids) + follow-along YouTube days |
| 200+ programs | AI-generated program from her questionnaire, editable |
| Tracker mode: sets × reps × kg, timers | Live session tracker with rest timer, prefilled from last time |
| Exercise swap (easier / harder / no equipment) | Swap by shared primary muscle, filtered by her kit |
| Last weight + records | Last performance, PRs (heaviest, e1RM, reps, hold), progression hint |
| Apple/Google Health | Session → `Workout`, deduplicated against band data at read time |

## Features

### F1. Ćwiczenia — the catalog ✅ (P1)
- `/trening/cwiczenia`: search (PL/EN, diacritic-insensitive), filters: muscle (dropdown, or tap
  the silhouette on desktop / sheet on phone), "Do domu", "Z filmem", equipment, level.
- Muscle filter matches primary **or** secondary (upstream tags most lunges/hip work with glutes
  only as secondary), primary matches first.
- Exercise sheet (`?e=<id>`): video (click-to-load youtube-nocookie) or a YouTube search link until
  one is picked; start/end photos alternating like a GIF; front/back body map (primary = accent,
  secondary = warm accent); Jak wykonać; Na co uważać; Częste błędy.
- Photos are fetched from GitHub on first request, re-encoded to WebP and cached in the images
  volume (`exercises-v1/`).

### F2. Opisy i wideo ✅ tooling (P2) — batches still to run
- `PATCH /exercises/{id}`, `POST /exercises/enrich` (≤ 50, per-item errors), `POST /exercises`.
- Every `youtubeId` is checked with YouTube oEmbed (404 → doesn't exist, 401 → not embeddable);
  title + channel stored. Agents must never guess ids.
- MCP: `search_exercises`, `get_exercise`, `enrich_exercises`, `add_exercise`.
  Command: `/wzbogac-cwiczenia [n | partia]`. Coverage counter on the catalog header.

### F3. Plan z ankiety (P3)
Training profile (goal, days/week, minutes, weekdays, location, home kit, styles, limitations),
program → weeks → days → exercises (sets, rep range or seconds, rest, target kg, superset), one
active program per person, "Dziś" view, `/plan-treningowy`.

### F4. Trening na żywo (P4)
Session snapshot of the day's targets, set rows prefilled from last time, rest timer + wake lock,
swap (this session / in the plan), finish with feel + note, Historia.

### F5. Rekordy i progresja (P4)
Last performance, PRs, double-progression hint per equipment step.

### F6. Aktywność bez dublowania (P4)
Finishing creates a `Workout` (`Source = Training`, MET estimate). `ActivityService` decides at
read time: band Active samples overlapping the window → estimate not added; overlapping HC
workout → one merged row.

### F7. Treningi z filmem (P5)
Follow-along video library (pilates/HIIT/yoga), player with a timer and "Zrobione", favourites,
progress charts, weekly per-muscle heatmap on the body map.
